======================================================================
                         ACTIVITY STUDIO
           Open Rails & MSTS Activity Creation Suite
======================================================================

Thank you for downloading Activity Studio!

Activity Studio is a modern tool built for train simulation enthusiasts
to easily inspect routes, create and edit train consists, manage paths,
configure services, and build complete Open Rails activities.


----------------------------------------------------------------------
1. SYSTEM REQUIREMENTS
----------------------------------------------------------------------
- Windows 10 or Windows 11 (64-bit only)
- Microsoft .NET Desktop Runtime (x64)
- DirectX 11 capable GPU and updated display drivers
  (Required for the 3D trainset preview)
- An installed Open Rails profile or MSTS folder containing
  "ROUTES" and "TRAINS" directories.


----------------------------------------------------------------------
2. HOW TO RUN / INSTALL
----------------------------------------------------------------------
- If you downloaded the Installer (.exe):
  Run the installer executable and follow the setup instructions.

- If you downloaded the Portable ZIP:
  Extract all files from this archive to a folder on your drive
  (e.g., C:\Activity Studio) and launch "Activity Studio.exe".
  
* WINDOWS SMARTSCREEN NOTE:
  If Windows displays "Windows protected your PC", click:
  "More info" -> "Run anyway".


----------------------------------------------------------------------
3. GETTING STARTED
----------------------------------------------------------------------
1. Launch Activity Studio.
2. Click "Files" -> "Select Installation Folder..." (or press Ctrl+O).
3. Select your Open Rails root folder or MSTS base directory.
4. Navigate through the top tabs:
   - Route     : Select and inspect your route.
   - Consists  : Create and edit train consists (.con) with 3D viewer.
   - Paths     : View and manage train paths (.pat).
   - Services  : Define player and AI train services (.srv).
   - Activities: Assemble activities (.act), briefings, and AI traffic.


----------------------------------------------------------------------
4. LOGS & SUPPORT
----------------------------------------------------------------------
If you run into any issues:
- Go to "Help" -> "Open Log File" in the application menu.
- Report issues or share feedback from Help menu in App
